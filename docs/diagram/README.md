# Architecture diagram source

`docs/architecture.svg` (shown in the main README) is generated by `build_architecture.py`.
To change it, edit the layout in the script and run:

```bash
python3 docs/diagram/build_architecture.py
```

It uses only the Python standard library and inlines the icons, so the SVG is a single self-contained file.

**Conventions:** planned resources (Auto Scaling group, RDS read replica, CloudWatch) have an orange label
with "planned" underneath and a faded icon; the Auto Scaling group sits in a dashed, light-orange area, and its
connection from the ALB is a dashed orange arrow. Deployed resources use normal colours and solid arrows.
Restyle an item as deployed once it actually is.

## Icons

`icons/` contains the official **AWS Architecture Icons** (© Amazon Web Services), used as AWS intends for
architecture diagrams. The files were copied unmodified from the npm package
[`aws-icons` 3.3.0](https://www.npmjs.com/package/aws-icons), which repackages the AWS icon set. That
package's licence is in `icons/LICENSE-aws-icons-npm.txt`.
